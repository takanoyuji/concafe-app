## 判断の要点

- **全員業務委託なので、キャスト向けには「報酬」の語で 稼働報酬 / 売上連動報酬 の2本だけ。** 時給・労働時間・基本給・通勤手当・バック率・最低賃金は API の型にも画面にも出さない（`lib/castPortal.ts` の `CastRewardMonth` がその制約）
- **確定は店長の明示操作。** 確定済みは計算実行で上書きできず（409）、削除もできない。`SalaryPeriodLog` に確定/解除を記録
- 未確定は「速報」。保存済みなら保存値、無ければライブ計算（Airレジ取込＋remodri＋みせ勤打刻。直近3ヶ月のみ）。進行中の期間は「前日まで」で判定・集計する（当日以降を要求すると月末まで永遠に「集計中」になる）
- 100円丸めの差は売上連動報酬に寄せ、稼働報酬がマイナスに見えないようにした
- `SalaryCastRecord.castCode` を保存し、本人の行はコードで引く。旧レコード（castCode 空・salary 0）は hpName と payment で代替
- 遠隔の日次は remodri の `groupBy=date&storeCode=`（キャストの所属店舗基準）

## 運用メモ

- 招待は管理画面 → キャストマスタ → 行の「ログイン」列の「招待」。メールは Resend で `APP_URL` のリンク。7日で失効
- キャストのログインは客と同じ `/auth/login`。ログイン後は `/cast/me`
- 報酬の「確定」は給与履歴の各期間の「確定」ボタン。確定すると「解除」に変わる
- 「売上」タブは店舗×月。来店は前日まで（Airレジは毎朝8時取込）、遠隔は現在まで
