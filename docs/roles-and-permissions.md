# ロールと権限（2026-09-18）

| ロール | 誰 | 入れる場所 | 既定の権限 |
|---|---|---|---|
| OWNER（オーナー） | 高野。旧 `ADMIN` | 管理画面 | すべて。権限管理と店長の招待はここだけ |
| MANAGER（店長） | 招待時にオーナーが指定 | 管理画面 | 権限管理以外すべて（全店舗共通） |
| CAST（キャスト） | キャストマスタから招待 | キャストページ | 自分の報酬（常に）＋キャスト売上（既定で可） |
| CUSTOMER（客） | 会員登録 | マイページ | 管理側の機能なし。**ロールのラベルも出さない** |

- 判定は `lib/permissions.ts`。機能 × ロールの既定に `RolePermission` の上書きを重ねる。60秒キャッシュ（保存時に破棄）
- API は `requireFeature("<機能>")`（`lib/authz.ts`）で機能ごとに 403 を返す。`session.role === "ADMIN"` の直書きは無くした
- proxy.ts は `/admin` を OWNER / MANAGER（旧 ADMIN）に絞るだけ。機能の可否はページと API で
- 旧セッション（JWT の role が `ADMIN`）は `normalizeRole` で OWNER として読む。強制ログアウトにならない
- `prisma/seed.ts` は起動のたびに初期ユーザーを upsert する。**ロールは OWNER**（ADMIN のままだと migration の OWNER 化が毎回戻る）
- 権限管理（`/admin?tab=permissions`）: 店長 / キャスト × 機能のチェック表と、マスタに無い店長の招待、スタッフ一覧
- 招待: キャストマスタの「招待」で店長かキャストかを選ぶ（店長を選べるのはオーナー）。受諾で `User.role` が付く
- 管理画面はPCで左サイドバー（使える項目だけ）、スマホは上部のタブ。`/admin?tab=<key>` で直接開ける
