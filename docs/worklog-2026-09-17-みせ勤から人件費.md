## きっかけ

9/17 に店長から「基本給が入っていない」。調べると、アップロードした人件費CSV（エアシフト）が
9/1〜15 の全期間分になっておらず（店全体の労働時間 63:00、普段は250時間前後）、数日分しか入っていなかった。
CSVの手作業に依存している限り同じことが起きるので、自社の勤怠アプリ みせ勤 から直接作れるようにした。

## 作り

- `lib/misekin.ts` … attendance API を全ページ取得し、キャストコード別に
  基本給 = Σ round(実労働分/60 × その日の時給) / 通勤手当 = Σ 交通費 / 労働時間 = Σ 実労働分 にまとめる
- `lib/salary.ts` … `calculateSalaryFromRows()` の人件費入力を `ArrayBuffer | MisekinWages` にした。
  CSVはエアシフト氏名、みせ勤はキャストコードで引く。計算式は変えていない（テストで CSV と同値を確認）
- `app/api/admin/salary/route.ts` … `wageSource=misekin` のとき CSV 不要。`MisekinError` は 400（データ不備）/ 502（接続）
- `app/admin/page.tsx` … 「人件費の出どころ」ラジオ。`.env` に設定があるときだけ出す（`/api/admin/salary/history` が `misekinConfigured` を返す）。既定はCSV
- 名寄せは **みせ勤の社員コード ＝ castCode**。表示名では突き合わせない（「月瀬透」vs「透」の揺れがある）

### 止める条件（黙って0にしない）
- 時給が未登録の打刻がある → 400 で該当者を列挙
- 退勤打刻が無い打刻がある → 400 で日付と名前を列挙
- 期間に打刻が0件 → 400
- 社員コードがマスタに無い人 → 計算から外して画面に警告（CSVで氏名が合わない人と同じ扱い）

## ⚠️ まだ使えない — 時給と交通費が みせ勤に1件も無い

星狼29人とも `wage_histories` / `transportation_histories` が0件。今の状態で「みせ勤」を選ぶと
3店とも「時給が登録されていない人がいます: …」で止まる（本番APIで確認済み）。
**みせ勤のスタッフ設定で時給（必要なら交通費）を入れるまで、実運用はCSVのまま。**

打刻の普及もまだ途中（東京 9/3〜9/16 で32件。エアシフトの同期間は約250時間分）。
切り替えるときは、同じ期間を CSV と みせ勤 の両方で計算して基本給を突き合わせてから。
